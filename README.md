# AEP Robotic Arms — coursework

Student: Jackson Sixtus Abetianbe (GitHub: Jae3y)

This repository contains the Arduino sketches for the AEP Robotic Arms track. Build and simulate each circuit in TinkerCAD Circuits with an Arduino Uno. The `iot_ldr_led` folder is from the separate IoT track and is outside this robotic arms submission.

## Required tasks

| Task | Folder | TinkerCAD pin map |
|---|---|---|
| Week 1 pushbutton LED | [week1_pushbutton_led](week1_pushbutton_led/) | Button D2, LED D13 |
| Week 2 traffic light | [week2_traffic_light](week2_traffic_light/) | Red D13, yellow D12, green D11 |
| Assignment A, six joints | [assignment_A_6dof_arm](assignment_A_6dof_arm/) | Servo signals D3/D5/D6/D9/D10/D11; pot wipers A0–A5 |
| Assignment B, ultrasonic reading | [assignment_B_ultrasonic_fixed](assignment_B_ultrasonic_fixed/) | HC-SR04 TRIG D9, ECHO D10 |
| Assignment C, smart gate | [assignment_C_parking_assist](assignment_C_parking_assist/) | HC-SR04 TRIG D9, ECHO D10; servo D6; buzzer D4 |
| Capstone, manual/autonomous arm | [separate repository](https://github.com/Jae3y/aep-robotic-arm-capstone) | See capstone repository README |

Each task README explains the wiring and sketch. Simulation evidence is not represented as complete until the TinkerCAD circuit has been run and captured.
